# PgBouncer

PgBouncer доступен на `localhost:6432`. В compose используется transaction pooling: соединение PostgreSQL закрепляется за клиентом только на время транзакции. Это подходит для коротких прикладных запросов, но не для сценариев, рассчитывающих на сохранение состояния сессии между транзакциями. Миграции и административные команды запускайте через прямое соединение на 5432.
